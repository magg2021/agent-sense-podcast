Agent Memory is More Than RAG

Guest: Ran Aroussi — Founder, MUXI

Agents sit on massive amounts of enterprise data — but still ask users to repeat themselves. RAG alone doesn't fix this. Ran Aroussi, founder of MUXI and creator of the yfinance library, walks through what a real agent memory system looks like: ingestion, distillation, graph relationships, and retrieval that reasons over context — not just similarity.

Key takeaway: Agent memory is an organizational knowledge system — build it to reason over context, not just search for similarity.

Why IT Service Agents Fail in Production — A Data Readiness Problem

Data Data Readiness IT Operations

Agent failures in production are usually data failures, not model failures. Using an IT service ticketing example, this episode shows how incomplete ownership records and stale configuration data cause agents to act confidently on wrong information.

Data Architecture Autonomy

Integration Will Decide Enterprise AI — MCP and Agent-to-Agent

MCP Integration Architecture A2A

When agents need to reach enterprise systems and coordinate with each other, integration becomes the bottleneck. MCP standardizes agent-to-system connections. Agent-to-Agent (A2A) protocols let work move across the enterprise without custom wiring for every handoff.

Key takeaway: Integration is the actual bottleneck in enterprise AI. MCP connects agents to systems; A2A connects agents to each other. Without both, every new workflow requires custom wiring.

MCP Gateway: The Control Layer for Enterprise Agents

MCP Governance Security Architecture

Connecting agents to enterprise systems creates a new exposure: unmanaged access across HR, finance, IT, and operations. This episode covers how an MCP Gateway sits between agents and core systems, enforcing identity, policy, approvals, and audit trails before any action reaches production data.

Key takeaway: An MCP Gateway is the control point between agents and enterprise systems — managing identity, approvals, and audit trails so that access is governed rather than open.

The Evolution of Agents — From Chat to Computer Use

Architecture Computer Use Observability

Governed Catalog of Agentic AI Assets

Governance MCP Architecture Reuse

As AI scales past the pilot phase, teams build agents and tools in isolation — creating sprawl, duplicate builds, and unclear ownership. A governed catalog gives enterprises visibility, reuse, and trust signals before agents reach production.
